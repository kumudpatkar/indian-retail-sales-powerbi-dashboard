# Indian Retail Sales Performance & Target Analysis Dashboard

![Dashboard Preview](dashboard-screenshot.png)

## 📌 Project Overview
This project is an end-to-end **Business Intelligence (BI) dashboard** built in **Microsoft Power BI** to evaluate retail sales performance across India. The dashboard tracks key revenue metrics, profitability, order volume, and actual sales against monthly targets across product categories, sub-categories, cities, and states.

---

## 🎯 Business Objectives
* **Track Core KPIs:** Monitor Total Sales, Total Profit, Total Orders, Total Quantity Sold, and Profit Margin %.
* **Evaluate Target Achievement:** Compare Actual Sales against Sales Targets on a monthly basis and across product categories.
* **Identify Top-Performing Regions:** Analyze state-wise and city-wise sales contributions using interactive maps and slicers.
* **Uncover Product Profitability:** Break down performance across Categories (Electronics, Furniture, Clothing) and Sub-Categories to spot high-margin and loss-making items.

---

## 🛠️ Tools & Skills Demonstrated
* **Power BI Desktop:** Data modeling, relationship management, interactive report design, and custom visual formatting.
* **Power Query (ETL):** Data cleaning, handling missing values, data type standardization, and date table creation.
* **DAX (Data Analysis Expressions):** Created custom calculated measures including:
  * `Total Sales`, `Total Profit`, `Total Orders`, `Total Quantity`
  * `Profit Margin %`
  * `Sales Variance` & `Target Achievement`
* **UI/UX Design:** Custom cohesive color palette, KPI cards with custom icons, and an interactive state-level slicer bar.

---

## 📊 Key Dashboard Components
1. **Executive KPI Cards:** High-level summary of overall business health (`Total Sales`, `Total Profit`, `Total Orders`, `Total Quantity`, `Profit Margin %`).
2. **Sales vs. Target Analysis:** Clustered column charts comparing actual monthly performance against set targets.
3. **Geographical Insights:** Interactive map visual (`Graphical Sales`) paired with state-wise and city-wise breakdowns.
4. **Category & Sub-Category Performance:** Donut chart, bar charts, and a detailed **Business Performance Summary** matrix comparing Clothing, Electronics, and Furniture.
5. **Interactive State Slicer:** Bottom navigation bar allowing users to dynamically filter the entire report by Indian state (e.g., Madhya Pradesh, Maharashtra, Gujarat, Delhi, etc.).
